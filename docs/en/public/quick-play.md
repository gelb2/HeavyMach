## Play with a keyboard and trackpad

You can play the Mac app and web/PWA version with a keyboard and trackpad. Move, jump and switch weapons with the keyboard. Click a point on the battlefield to aim and fire there; hold the click to keep firing at the weapon's firing rate. You can also use a keyboard and trackpad together on iPad.

| Default key or input | Action |
|---|---|
| A / D | Move backward / forward |
| Space | Jump |
| Trackpad click / hold | Aim and fire at that point in manual mode |
| Arrow keys | Adjust manual aim |
| F / hold F | Fire |
| Q / E | Previous / next weapon |
| Shift | Fine movement and aiming |
| R | Switch auto-aim target |
| Esc | Pause / resume; go back in menus |
| Tab / Shift+Tab, Enter | Move between menu items; select |
| F2 | Key settings |
| F3 | Open recovery codes on the save-slot screen |
| ⌘Q | Quit the Tauri Mac app |

Click the on-screen **A button** to turn auto-aim on or off. The keyboard **A key moves backward**. With auto-aim on, hold **F** or click the on-screen crosshair fire button to shoot. Clicking the battlefield does not select a target or fire in this mode.

If F2 or F3 controls brightness or a system feature on your Mac, hold **Fn or 🌐** as well. [Apple function-key instructions](https://support.apple.com/ko-kr/102439).

To change a key, press **F2 → select an action with Up/Down → Enter → press the new key**. Assigning an occupied key swaps the bindings. Backspace restores the defaults. [Full controls](gameplay-guide.md).

## First launch on Mac

Requires an Apple Silicon Mac and macOS 14 or later. Unzip the download, move **Heavy Mach Desktop.app** to Applications, then open it.

The current download is not notarized by Apple, so macOS may block its first launch.

1. Try opening the app once.
2. Open **System Settings → Privacy & Security**.
3. Scroll down to the Heavy Mach Desktop message and select **Open Anyway**.
4. Select **Open** in the next dialog.

[Apple first-launch instructions](https://support.apple.com/102445).

### Import the recovery code

1. On the game's save-slot screen, select **TRANSFER PROGRESS**. First use **CREATE CODE → COPY** to keep a copy of your own progress elsewhere.
2. Copy the shared code below, paste it into the input field and select **CHECK CODE**.
3. On web, PWA, Tauri and Android, choose **FROM 2** and your preferred **TO** slot to preserve the other slots. **SETTINGS OFF** keeps your current HUD, key and aim settings.
4. Select **RESTORE**, check the displayed slot and level, then select **RESTORE** again.
5. Start the restored slot. If you imported all slots, choose **slot 2**.

**iPhone, iPad and native Mac replace all three slots and the HUD, key and aim settings.** Importing all slots also applies the empty slots 1 and 3. Web-based versions return to the launcher after restoring; select **PLAY** to enter again. [Restore scope by platform](save-recovery-20261102.md).
