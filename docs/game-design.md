# HeavyMach 게임 기획

## Apple 플랫폼 확장 — 2026-10-26

2026-10-29 지원 범위: Mac 앱과 iOS 시뮬레이터는 Apple Silicon arm64만 지원한다. Intel Mac은 지원하지 않는다.

2026-10-26 추가 범위는 iPhone·iPad·native Mac, 공용 코드/자원 모듈, 가변 화면, 키보드 전 조작이다. [구조](apple-platforms.md), [입력](keyboard-input-policy.md)을 따른다. 자동조준은 전용 브랜치의 치트 앱에서 개발·검증한다. 후속 사용자 지시로 정식 앱에도 A 버튼으로 자동조준을 제공한다. HUD 배치 편집은 일시정지의 SET GAME UI에서 제공한다.

2026-10-25 현행 요구. HeavyMach 1.13 복원 제품에 적용한다. 별도 Unity 게임 기획과 섞지 않는다. 원본 함수·수치는 [복원 계약](restoration-contract.md)과 분야별 정책이 상세를 소유한다. [문서 위계](document-governance.md)에 따라 기술 설계와 실제 앱에 연결한다.

## 제품 의도와 플레이

원작의 탱크 전투, 이동·점프·조준, 무기 획득·전환, 경험치·부품 강화, 미션 진행을 현재 아이폰에서 플레이하게 한다. 원본 에셋·맵·게임 수식과 저장을 보존하면서 사용자가 승인한 넓은 화면과 중단/재개 편의를 제공한다.

화면 흐름은 타이틀 → 슬롯 → 모드/미션 선택 → 전투 → 결과/다음 스테이지 또는 메뉴다. Scenario와 Survival을 구분한다. 생성·삭제·선택되는 슬롯과 앱 재실행 후 진행 복구는 원본 저장 규칙을 따른다. 원작에 없는 적 레벨 보정·데미지·사거리·성장 곡선을 임의로 넣지 않는다.

일반 앱은 게임용, 치트 앱은 무기·부품·시작 조건과 방향 입력을 설정하는 별도 검증용이다. 같은 게임 코어를 사용하며 저장 공간을 분리한다. 일반 난이도 플레이와 치트 조건 검사는 각각 결과를 기록한다.

## 화면·아트 기준

원본 탱크·지형·효과의 크기와 화풍을 유지한다. 타이틀·선택 배경은 중앙 원본과 좌우 확장 그림이 연결되어 보여야 한다. 생성 이미지의 중앙을 원본 대신 쓰지 않는다. HUD·글자·버튼은 안전영역과 읽기 쉬운 비율을 지키며 배경과 같은 방식으로 무조건 늘이지 않는다. 아트 채택은 원본/생성본 단독 이미지와 실제 앱 합성 화면을 함께 확인한다.

현재 타이틀·슬롯·모드·미션 확장은 적용됐다. 2026-10-27 첫 실행 타이틀·슬롯·모드·미션 배경과 결과 일러스트의 Simulator 검사를 완료했다. 새 도어의 실기기 검수는 남아 있다. 코드의 OpenGL 구조를 설명하는 design.md와 이 시각·사용성 요구를 구분한다.

## 추가 지상 적: 쉴카·퉁구스카

2026-10-28 요구로 두 차량을 추가한다. 실차 형태를 유지한 새 파츠를 원작의 지상 이동·조준·반동·피격에 연결한다. 쉴카는 흰색 총탄 6발, 퉁구스카는 흰색 총탄 4발과 미사일 2발을 발사한다. 레이더는 독립 회전하며 이동 중 차체와 포신이 덜컹거린다. 7개 미션의 기존 Tank 수에 약 1.3배인 총 152대를 35개 스테이지에 배분한다. [수량과 구현](ground-aa-expansion.md).

### 소형 지상 유닛의 크기·부품 비율 — 2026-10-28 사용자 확인

보고 사이트에서 비슷한 길이의 원작 적 유닛과 비교한 결과, 사용자는 현재 쉴카·퉁구스카의 전체 크기와 부품별 비율이 이 유형의 작은 전차 유닛에 적합하다고 평가했다. 두 차량 중 차체·포탑 등 부품 간 비율의 우선 참고 기준은 퉁구스카다.

쉴카 포탑의 세로 확대(16→29)는 원형 비율을 의도적으로 바꾼 사용자 승인 예외다. 이를 실차 비율을 정확히 재현한 결과로 설명하지 않는다. 후속 유사 크기의 지상 유닛은 현재 퉁구스카의 차체·포탑 비율과 비슷한 길이의 원작 적을 나란히 놓고 전체 크기·부품 비율을 비교한다. 이 평가는 다른 실물 유닛의 비율을 임의로 바꾸는 허용으로 확대하지 않는다.

## 웹 실행 — 2026-10-28

HeavyMach 1을 브라우저에서 실행하는 일반 앱 웹 빌드를 추가했다. 게임 규칙·에셋·저장 형식은 iOS와 같다. 데스크톱은 마우스·키보드, 휴대폰은 터치·틸트를 사용한다. 휴대폰 실기기 확인과 공개 배포는 남아 있다. [이식 문서](web-port-20261028.md).
