# 쉴카·퉁구스카 구현

정본: [canonical](canonical.md). 요구·과제: [HM-GROUND-AA](usability-todo.md). 그림과 게임 화면: [보고서](public/ground-aa-art-20261028.md).

## 요구와 무장

2026-10-28 지시: 두 차량의 외형·파츠를 새로 그리고 원작의 지상 이동·조립·무기 코드를 사용한다. 레이더는 포신 조준과 독립적으로 회전한다. 기존 적 배치를 유지하면서 모든 미션에 추가한다.

| 차량 | 기관포 | 미사일 |
|---|---|---|
| 쉴카 | 흰색 총탄 6발, 발사 간격 0.2초 | 없음 |
| 퉁구스카 | 흰색 총탄 4발, 발사 간격 0.2초 | 2발, 발사 간격 0.5초 |

발사 수·흰색 탄환은 사용자 지정이다. 묶음 안 간격은 구현 값이다. 기관포는 `E_Tank_Wpn_01`의 흰색 `BulletEffect.png`, `Normal` 효과와 `Wpn_EnGun`을 사용한다. 미션별 피해·속도는 해당 번호의 `E_Tank_Wpn_01..07`을 따른다. 미사일은 `E_ArmoCar_Msl_01..05`를 복사한다. 퉁구스카의 기관포와 미사일은 별도 무기 상태로 조준·연사한다. 원래 무기의 데이터는 수정하지 않는다.

## 파츠와 움직임

`GroundAA.cpp`가 `MachPartDefinition`으로 차체 → 포탑 → 기관포·레이더·미사일을 연결한다. `Enemy.cpp`의 지상 AI와 `Motion.cpp`의 지형 충돌·경사 회전을 사용한다. `Visuals.cpp`가 포신 상하 조준·반동을 처리한다.

차체 그림은 2프레임이다. 원작처럼 3논리 좌표 단위 넘게 이동하면 다음 프레임으로 바뀐다. 새 차량에만 기존 `useEngineBounce`를 켰다. 평지에서도 차체·포탑은 최대 1.35, 무기는 그 절반만큼 위아래로 움직인다. 원작 적의 설정은 그대로 둔다.

레이더는 8방향 그림을 0.25초마다 전환해 2초에 한 바퀴 돈다. 부모 장착점과 차체 기울기를 따르면서 자체 각도를 바꾼다. 퉁구스카의 전방 원형 추적 레이더는 포탑 그림에 고정했고, 후방 사각 탐색 레이더가 돈다. 게임 시계를 사용해 일시정지하면 함께 멈춘다.

생성한 원본 PNG 11개는 `Art/Extensions/GAA_*`에 보관했다. 부품 영역·표시 크기는 `GroundAAArt.inc`에 있다. `HMMedia`가 처음 읽을 때 해당 부품만 잘라 게임 크기로 축소하고 캐시한다. 게임 시작 전에 새 파츠의 모든 프레임을 GPU에 올린다. 이후 이동·레이더 회전에서 이미지 파일을 다시 읽거나 저장하지 않는다. 작성 프롬프트·생성 파일·해시는 `Art/GroundAA/20261028-runtime`에 보관했다.

## 크기와 연결부 수정 · 2026-10-28

원작 Tank001의 차체 한 프레임 85×30을 기준으로 차체 폭을 쉴카 104→80, 퉁구스카 112→85로 줄였다. 당시 차체 크기는 80×18과 85×22였다. 포탑은 51×14와 50×23, 후속 지시로 포신은 32×9와 37×7로 줄였다. 레이더 높이는 16과 13이며 방향별 폭은 그림 비율을 따른다.

기존 연결점은 파츠 그림의 사각형 끝만 맞춰 차체 지붕의 투명 영역만큼 틈이 남았다. 차체 상단 소켓은 첫 수정에서2만큼 내렸고, 쉴카는 후속 틈 지적으로 총4만큼 내렸다. 두 레이더 장착점은 포탑 중심에서Y=2로 지정해 실제 표면과 겹친다. 포·미사일의 축과 포구, 레이더 장착점, 전체 피격 범위와 체력 막대 높이를 새 크기에 맞췄다.

실차 사진을 대조해 두 포신과 레이더 그림 4개를 교체했다. 쉴카 포신의 두 쌍 배치·포구·원형 레이더 본체, 퉁구스카의 가는 포신·냉각부·낮은 후방 레이더 받침을 수정했다. 생성 원본·프롬프트·교체 전후 해시는 `Art/GroundAA/20261028-refinement`에 있다. [수정 화면](public/ground-aa-art-20261028.md).

## 체력과 배치

각 미션 패키지의 원작 Tank 계열 등장 수에 1.3을 곱하고 반올림한 수를 **쉴카·퉁구스카 합계**로 추가한다. 35개 서브미션에 적어도 한 대씩 배분하고, 남은 수량은 원작 전차 수와 안전하게 착지할 수 있는 지점 수에 따라 나눈다. 7개 패키지마다 두 종류가 모두 등장한다. 합계는 152대다. 메뉴에 없는 빈 8번째 패키지는 열지 않는다. Survival은 이번 배치에 포함하지 않는다.

## 검사

- `HMAppleInputTests/testGroundAAMediumSizeAndTurretJoin`: 원작 전차 2종과 신규 차량 2종을 평지에 놓고 실제 렌더러로 비교 캡처.

- `GroundAATests`: 차체 폭과 평지·경사·흔들림에서 포탑 접합면 겹침, 기존 배치·무기 값 보존, 35개 서브미션 수량, 6/4/2발과 간격, 일시정지, 레이더 8방향, 중복 등록 방지.
- `GroundAARuntimeTests`: 추가 152좌표의 착지·좌우 이동, 플레이어 20무기 × 차량 2종의 실제 탄환 충돌·피해·파괴 40조건.
- `HMAppleInputTests/testGroundAAAssemblyRadarWeaponsAndNoShotSave`: 실제 앱의 파츠 그림, 레이더·궤도 프레임, 사격, 정지·재개, 저장 호출과 OpenGL 출력.

원작 코드가 지면 높이를 구할 때 사용하는 긴 선분은 실제 낙하 경로와 다른 선분을 고를 수 있었다. 첫 배치 검사에서 Stage25의 x=1700에 생성된 차량이 낙하했다. 배치 후보마다 실제 착지 코드를 실행하도록 고쳤고 152좌표가 모두 통과했다.

현재 검사 결과는 [검증 기록](evidence/ground-aa-20261028.json)에 정리한다. 미션 전체의 난이도·장시간 발열 검사는 후속 과제다.

## 후속 외형 과제

포신 실차 비율 대조, 고정 속도 좌우 이동 계측, 레이더24방향·질감·차체 자세 개선안은 [보고서](public/ground-aa-art-20261028.md)에 정리했다. 실제 이동 계측에서 신규 차량의 상하 이동폭은1.35, 차체2프레임 전환을 확인했다. 사용자의 2026-10-28 후속 지시로 덜컹거림과 차체 자세는 현재 수준을 유지한다. 차체 자세 재제작 계획은 취소했다. 색·질감 개선은 기존 파츠 크기·연결점·프레임 배치를 보존하는 방식으로 진행한다.

## 새 시안 파츠 적용 · 2026-10-28

`feat/ground-aa-refinement`에서 새 파츠 시트2장·레이더 시트2장을 적용했다. `Art/GroundAA/20261028-integrated/manifest.json`의 영역·크기·축 정보로 `GroundAAArt.inc`를 생성한다. 기존 제작 PNG는 남겨 두고 런타임 이름을 새 시트 영역에 연결했다. HMMedia의 기존 축소·GPU 준비·캐시 경로를 사용한다.

포탑 그림에 고정 받침을 넣었고, 독립 레이더는2초 동안24프레임을 순환한다. 축의 X·Y 오차를 차량 회전으로 변환한다. `GroundAATests`는 평지·경사·덜컹거림에서 모든 프레임의 축이 같은 장착점에 붙는지 검사한다. 무장·배치·engineBounce 코드는 유지했다.

[실기기 검사와 화면](public/ground-aa-art-20261028.md#integrated), [검사 기록](evidence/ground-aa-integrated-20261028.json).

## 쉴카 포탑 후속 수정 — 2026-10-28

`GAA_Shilka_Turret_v3.png`는 실차 사진을 참조해 장갑 측면과 뒤쪽 부피를 늘린 별도 그림이다. 이전 긴 안테나 두 개를 제거했다. 전체 파츠 크기51×16은 유지하면서 몸통이 차지하는 높이를 늘렸다. 레이더 장착점은 (14,8)이며 포탑 바닥·포 축은 유지한다. 퉁구스카는 변경하지 않았다. 현재 파츠 목록은 `Art/GroundAA/20261028-shilka-turret/manifest.json`이다. [실제 게임 화면과 검사](public/ground-aa-art-20261028.md#shilka-turret).

후속 사용자 지시로 쉴카 포탑의 전체 표시 높이를16에서29로 늘려 퉁구스카와 맞췄다. 폭51·PNG는 유지했다. 바닥(0,-14.5)·포 축(-19,-1.8125)·레이더(14,14.5)를 적용했다. [비교 화면](public/ground-aa-art-20261028.md#matched-height).

## 현재 비율에 대한 사용자 확인 — 2026-10-28

현재 두 차량의 전체 크기와 부품별 비율은 비슷한 길이의 원작 적과 비교해 적합하다는 사용자 평가를 받았다. 특히 퉁구스카의 차체·포탑 비율이 쉴카보다 더 좋은 기준이다. 쉴카 포탑 높이29는 원형 비율을 고의로 바꾼 승인 예외로 유지한다. 이후 비슷한 길이의 작은 지상 유닛을 만들 때는 퉁구스카를 우선 참고하고, 원작 적과 실제 게임 화면에서 나란히 비교한다. [기획 기준](game-design.md).
