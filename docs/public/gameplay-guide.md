# HeavyMach 조작

<!-- language-nav:start -->
[한국어](gameplay-guide.md) | [English](../en/public/gameplay-guide.md)
<!-- language-nav:end -->

기기를 가로로 놓고 슬롯과 미션을 선택한다. 일반 앱은 플레이 진행에 따라 무기와 부품을 얻는다. 치트 앱은 타이틀의 검증 패널에서 미션·무기·강화 조건을 지정할 수 있다. 두 앱은 저장 공간이 다르다.

## 터치와 틸트

iPhone·iPad·Android 기기를 기울이면 탱크가 앞뒤로 움직인다. 화면의 공격할 지점을 터치하면 포신이 그 방향을 향하고 무기가 발사된다. 점프 버튼으로 장애물을 넘고, 무기 버튼에서 공격 수단을 바꾼다. 화면 왼쪽·오른쪽으로 기기를 눕힌 두 가로 방향을 지원한다.

메뉴 버튼을 누르면 전투가 멈춘다. 앱을 백그라운드로 보내거나 기기를 잠가도 정지하며, 돌아온 뒤 직접 재개한다. 전투 중 120초 동안 입력이 없으면 일시정지한다.

## HUD 위치 편집

게임 중 MENU를 누르고 일시정지 메뉴에서 **SET GAME UI**를 누른다. 버튼·계기판·상단 장식을 끌어서 옮긴다. 이동을 시작하면 오른쪽 도구가 접히며 **TOOLS**로 다시 연다.

**APPLY**는 배치 저장, **CANCEL**은 변경 취소, **RESET LAYOUT**은 기본 배치 복원이다. **PREVIEW**로 도구를 접고 게임 화면을 확인한다. 전투 중 들어갔다면 **SAMPLE SCENE**으로 탱크·지형·적이 있는 예시 장면을 볼 수 있다. 편집 중에는 전투가 멈춘다. 적용 후 **RESUME GAME**을 눌러 재개한다.

키보드로 편집할 때 F6으로 HUD 이동과 도구 버튼 선택을 전환한다. 도구 버튼은 Tab·Shift+Tab으로 고르고 Enter로 누른다.

[화면 예시](hud-improvement-plan-20261028.md).

## 자동조준

HUD의 **A 버튼**으로 켜고 끈다. 켜면 앞쪽에서 가장 가까운 살아 있는 적을 선택하고, 탱크의 이동·점프와 적의 움직임을 반영해 포신 각도를 계속 계산한다.

- 화살표 버튼: 다른 표적 선택.
- 조준경 모양 발사 버튼: 현재 포신 방향으로 사격. 누르고 있으면 무기의 연사 규칙에 따라 발사한다.
- 모서리·사선과 `LOCKED`·`TRACK`·`BLOCKED`: 선택한 적과 조준 상태 표시.
- 화면 밖으로 나간 표적: 선택 유지, 가장자리 방향 표시.
- 표적이 죽거나 탱크 뒤로 이동: 다른 전방 적 선택.
- 전방에 적이 없음: 기본 포신 각도. 발사 버튼은 그대로 사용할 수 있다.

자동조준 중 전장 터치는 표적 지정·사격에 쓰이지 않는다. 기존 대시 입력은 유지된다. 모드를 바꿀 때 누르고 있던 발사 입력을 해제하므로 다시 눌러 발사한다. 이미 날아간 탄환과 시작한 묶음 발사는 원래 규칙을 따른다.

자동조준은 포신을 조정한다. 탄속·분산·중력·피해량은 무기의 값을 사용한다. 지형에 가려진 적이나 빠르게 움직이는 적에게는 빗나갈 수 있다.

## 키보드

| 기본 키 | 전투 중 동작 |
|---|---|
| A / D | 후진 / 전진 |
| 방향키 | 조준 방향 조절 |
| F | 누르고 있는 동안 발사 |
| Space | 점프 |
| Q / E | 이전 / 다음 무기 |
| Shift | 세밀한 이동·조준 |
| R | 자동조준 표적 전환 |
| Esc | 일시정지·재개 |
| F2 | 키 설정 열기 |

키보드 **A 키는 이동**이다. 화면의 자동조준 **A 버튼**과 구분한다. 메뉴에서는 방향키·Tab/Shift+Tab으로 항목을 옮기고 Enter로 선택한다. Esc는 취소·상위 메뉴 이동에 사용한다.

키 설정에서 위아래 키로 동작을 고르고 Enter를 누른 뒤 새 키를 입력한다. 이미 쓰는 키를 지정하면 두 배치를 교환한다. Backspace는 기본 배치로 복원하고 Esc는 변경을 취소한다. 설정은 확정할 때 저장한다.

iPad는 터치와 키보드를 함께 사용할 수 있다. 이동 키를 놓으면 키보드의 가상 기울기를 해제하고 센서 입력으로 돌아간다. 창이 비활성화되거나 게임이 멈추면 누르고 있던 키 상태를 정리한다. 키보드 입력 구현과 실물 키보드 검사 상태는 [입력 정책](../keyboard-input-policy.md)과 [검증 결과](validation.md)에 있다.

## 복원 코드

저장 슬롯 화면에서 **TRANSFER PROGRESS**를 누른다. 키보드에서는 F3으로 연다. **CREATE CODE**로 현재 저장의 코드를 만들고 **COPY**로 복사한다. 다른 기기에서는 같은 창에 코드를 붙여넣고 **CHECK CODE**로 내용을 확인한다. **RESTORE**를 누른 뒤 복원할 내용을 확인하고 다시 **RESTORE**를 누르면 적용한다. **CANCEL**은 복원을 취소하고 **CLOSE**는 슬롯 화면으로 돌아간다.

## 무기·강화·미션

상단 무기 목록의 선택 테두리로 현재 무기를 확인한다. 기관포·산탄·미사일·광선·공중 지원은 각각 발사 간격과 궤적이 다르다. 탄약·재장전 상태를 보며 무기를 바꾼다. 적을 처치하고 경험치를 얻으면 레벨업 창에서 MOVEMENT·DEFENSE·ATTACK 중 강화할 항목을 선택한다.

스테이지를 마치면 결과 일러스트와 다음 스테이지·미션 선택 버튼이 나온다. 진행은 슬롯 선택, 다음 스테이지, 게임 오버, 메뉴 복귀 시 저장한다. 사격과 피격은 메모리의 게임 상태를 갱신한다.
