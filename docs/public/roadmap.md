# 남은 과제

<!-- language-nav:start -->
[한국어](roadmap.md) | [English](../en/public/roadmap.md)
<!-- language-nav:end -->

2026년 11월 2일 main 기준이다. v0.17은 Apple·Android 앱을 포함하며 이후 main에 웹/PWA·Tauri Mac·복원 코드·게임 버튼 교체가 추가됐다. 나는 설치된 iPhone·iPad 앱을 플레이하며 이상 동작을 보지 못했다. 아래에는 아직 수정하거나 검사할 일을 모았다.

## 버그와 성능

| 과제 | 현재 상태와 다음 작업 |
|---|---|
| 외부 알람 후 무음 | 알람 앱 때문에 백그라운드로 갔다 돌아오면 소리가 사라진다는 보고가 있다. 알람 중단·복귀와 오디오 세션·OpenAL 출력 상태를 함께 기록하고 메뉴음·무기음 복구를 검사한다. 원인은 아직 확정하지 않았다. |
| iPad 전투기 진입 시간 | v0.16 진입 호출 간격 p95 21.39ms가 기준 20ms를 넘었다. 수정 전 같은 조건과 대조한다. iPhone 진입·전투와 iPad 전투는 통과했다. |
| 네이티브 Mac 성능 | 11월 2일 p95 24.87~51.02ms가 16.67ms 기준을 넘었다. 메뉴·전투·HUD 편집별 처리시간과 호출 간격을 분리해 조사한다. [측정값](../evidence/game-buttons-apple-20261102.json) |
| 이전 표시시간 실패 | iPhone 메뉴와 공용 모듈 검사에서 남은 표시시간 실패를 조건별로 재현하고 원인을 분리한다. |
| 장시간 검사 | 이동·점프·사격·미션 전환 중 발열·전력·메모리를 측정한다. Mac HUD 편집의 처리시간도 조사한다. |
| 빌드 경고 | 전면 조사 전이다. deprecated API 관련으로 추정하며 플랫폼·일반/치트·Debug/Release별 경고를 수집해 원인을 확인하고 수정한다. |

## 조작과 게임 기능

| 과제 | 계획 |
|---|---|
| 자동조준 상태 | 표적 없음·화면 밖·지형에 가린 표적을 구별하는 표시를 만든다. 현재 선택·포신·탄환 계산은 유지한다. |
| 튜토리얼 | 기존 미션·저장을 유지하며 최상단에 0-0~0-4 다섯 미션을 추가하는 방법을 연구한다. 틸트·이동·점프·무기·재장전·필살기·자동조준을 실제 조작으로 배우게 한다. |
| 추가 적 난이도 | 새 지상·공중 적을 포함한 전체 캠페인에서 탄약·피해·필살기 사용·클리어 난이도를 확인한다. |
| 편대 전투 행동 | 생성·진입 분산은 v0.16에 포함됐다. 진입 후 편대 유지·회피와 화면 밖 이탈·재진입은 아직 구현하지 않았다. |
| 실물 키보드 | iPad Magic Keyboard의 웹 이동·점프·트랙패드 사격은 직접 확인했다. Bluetooth·USB 키보드의 연결·재연결·키 유지·터치 병용을 검사한다. |
| 적 AI와 넓은 화면 | 이동·활성 범위의 고정값이 화면 폭 변화에 영향을 받는지 후속 조사한다. |

## 빌드와 플랫폼

- Tauri Mac: [Tauri Mac 다운로드](https://github.com/gelb2/HeavyMach/releases/tag/tauri-mac-20261102) ZIP과 첫 실행 안내를 제공했다. Developer ID 서명·공증, 다른 Mac에서의 최초 실행, 업데이트·제거 검사가 남아 있다.
- Tauri Windows: Windows 빌드, WebView2 실행, 입력·음향·저장·종료와 설치본을 검증한다.
- Tauri와 네이티브 Mac 비교: 짧은 전투와 저장 검사는 끝났다. 장시간 성능·메모리·음향, 메뉴 전환의 긴 표시 간격을 추가 조사한다.
- 웹/PWA 보존: 실제 7·14·30·40일 미접속 뒤 저장 보존을 확인한다. 날짜를 바꾼 회귀 검사와 오프라인 재시작은 통과했다. 날짜 조정은 브라우저 저장소 삭제 시계를 바꾸지 않는다.
- 웹/PWA 추가 검사: iPhone·iPad·Galaxy의 브라우저/설치 모드별 업데이트·모션 권한·저장 복원을 반복한다. 공개 배포 뒤 코드 복원과 오프라인 재시작 검사는 통과했다.

- Xcode·Android Studio의 GUI 빌드·실행을 설치 문서 최상단에서 권장하는 방안을 조사한다. Git clone·LFS 이후 필요한 프로젝트 선택·설정과 외부 자료로 넘길 일반 사용법을 구분한다. [연구 과제](../usability-todo.md#hm-gui-install-guide).

- 다운로드·자원 검사·OpenAL 준비·빌드·실행을 연결하는 스크립트. Mac 실행과 iPhone·iPad 설치, 일반·치트 앱을 선택하고 개발 팀·서명을 안내한다.
- iPhone 무선 XCTest·Instruments 전체 실행과 두 기기의 재부팅 후 반복 설치·디버깅.
- Android 일반·치트 APK는 Galaxy에서 실행했다. 전체 캠페인 클리어·장시간 발열·태블릿 실기기·배포 서명을 진행한다. [개발 기록](android-development-20261030.md).
- 접힌 화면 위쪽에 게임, 아래쪽에 조작부를 두는 배치 연구.
- 릴리스 초안 생성 직후 목록 조회가 비어 중단되는 경우의 자동 재개. v0.17은 같은 초안을 확인하고 재개해 게시했다. [검사 기록](../evidence/release-v0.17-20261030.json).
