## 최종 채택 — 유로파이터 외부 포드 제거

2026-11-09 후속 지시: “유로파이터는 다른 럭스루나에들 처럼 미사일 포드 없이 간다. 그 외는 만든 버전 대로 간다.” 외부 포드를 제거했고, 나머지 몸체·도장·카모프·수치는 유지했다. 기존 럭스루나에와 같은 보이지 않는 무장 파츠와 고정 총구를 사용한다. 미사일 3연사와 실제 피해는 유지됐다. 생성 포드 원본은 과거 시안으로 보존하고 실행용 PNG 3개는 삭제했다.

아이폰 Air(iOS 27.2)에 치트가 없는 정식 앱을 무선 업데이트 설치했다. 서명과 실제 패키지 자원 116개를 대조했고 포드 PNG가 없음을 확인했다. Documents 2개 파일을 백업하고 설치 전후와 타이틀 실행 후 내용 일치를 확인했다. 타이틀 화면 확인 뒤 앱을 종료하고 홈 화면 복귀를 확인했다. 아이폰에서 신규 2종 전투를 직접 플레이한 결과는 아니다.

카모프 Ka-52와 럭스루나에 유로파이터를 구현했다. 두 기체는 실제 PNG와 MCH 파츠·무기 데이터로 조립하고 기존 공통 이동·사격·충돌·피해·파괴 경로를 사용한다. 웹 치트 빌드에서 두 기체의 공격과 파괴, 카모프의 두 로터 애니메이션을 확인했다.

카모프는 Heli006의 기체 유형·기본 HP300을 사용한다. 두 로터는 기존 type3·2프레임 애니메이션으로 움직인다. 두 로터 높이 차는 11이며, 두 프레임만으로 시계·반시계 반대 회전을 입증하지는 못했다. 기관포와 미사일은 별도 무기로 실제 탄을 발사한다.

## 발견해서 수정한 사항

첫 비교 화면에 메뉴와 타워가 겹쳐 기체를 가렸다. 메뉴를 닫고 동일 배율의 실제 게임 장면을 다시 촬영했다. 카모프 몸체 앵커는 원작 기준으로 맞췄고 기울어진 몸체와 게이지가 겹치는 경우는 기존 HMEX 게이지 오프셋으로 수정했다. 유로파이터의 붉고 흰 포드와 밝은 갈색 몸체는 새 시안으로 교체했다.

신규 파츠 삽입으로 기존 레코드 순서가 바뀌는 문제는 exporter가 원래 순서를 보존하도록 고쳤다. 이미지 검사는 파일만 같고 manifest가 달라진 경우도 실패하도록 보강했다. 실패 기록·수정 전 시안은 삭제하지 않았다.

독립 검토자는 최종 코드·데이터·v4 비교 화면에서 남은 차단 결함을 발견하지 못했다고 보고했다. 이는 사용자 시각 승인이나 실기기 검증을 대신하지 않는다.
