# 항공기 월드별 배치와 플랫폼 검사 — 2026-11-07

쉴카 77대·퉁구스카 75대, 합계 152대를 기준으로 Yak-141·Harrier GR3·F-35B의 합계를 152대로 맞췄다. 기존 항공기는 14개 스테이지에 113대였다. 수정본은 시나리오의 7개 미션·35개 스테이지 모두에 등장한다. 항공기 각 기종을 152대로 늘린 것은 아니다.

| 기종 | 이전 | 수정 후 |
|---|---:|---:|
| 쉴카 | 77 | 77 |
| 퉁구스카 | 75 | 75 |
| Yak-141 | 30 | 51 |
| Harrier GR3 | 41 | 51 |
| F-35B | 42 | 50 |

스테이지마다 항공기 합계가 해당 스테이지의 쉴카·퉁구스카 합계와 같다. 각 미션에 항공기 3종이 모두 나오며 기종별 차이는 최대 1대다. 1대만 추가되는 짧은 스테이지에는 한 기종만 나온다. [35개 스테이지 수량](../evidence/vtol-world-distribution-20261107.json).

기존 적 1,182개 항목의 이름·좌표·보스 여부·순서를 보존했다. 럭스루나에와 지상 방공 유닛도 기존 배치와 같다. 항공기 사이 간격 100, 보스와 간격 600을 유지했다. 짧은 보스 맵에는 맵 가장자리 제외 폭을 맵 폭의 15%까지 줄여 접근 구간에 배치했다. Survival은 변경하지 않았다.

## 실행 검사

| 대상 | 확인한 결과 |
|---|---|
| 공용 코어 | 25/25 통과. 35개 스테이지의 실제 생성 횟수, 재생성 방지, 배치·보스 간격·기존 적 보존 검사 |
| native Mac / iOS Simulator | 각 2/2 통과. 새 항공기 배치 렌더링과 지상 방공 유닛 회귀 |
| Galaxy SM-S731N | 일반·치트 앱 업데이트. 별도 치트 앱에서 35개 스테이지 진입 등을 포함한 39개 검사 통과. 일반 앱 타이틀 확인 |
| iPhone Air / iPad Air 13 M2 | 일반 앱 업데이트·실행. 설치 직후 Documents 해시가 설치 전과 같음. 아이폰 기존 슬롯·미션 선택, 아이패드 타이틀 확인 |
| 웹·설치형 PWA | Chrome GPU 설치 PWA 21개, 모바일 화면·입력 검사 7개 통과. 오프라인 재실행 포함. Safari 타이틀 확인 |
| Tauri Mac | Release 앱 설치, 기존 슬롯 로드, 미션 7-6의 적·탄환·전투 결과 렌더링, 정상 종료 확인 |

아이폰·아이패드의 별도 검증 앱은 무료 개발 서명의 설치 앱 3개 제한으로 설치 단계에서 막혔다. 이 두 실기기의 이번 항공기 전투 자동 검사는 수행하지 못했다. 기존 앱을 삭제하지 않고 시뮬레이터·Mac·코어·Galaxy 검사를 진행했다. 일반 앱 설치 성공을 실기기 전투 검사 성공으로 계산하지 않았다.

Tauri는 자동 조작 중 전면 활성화되지 않아 검은 화면이 유지됐다. Finder에서 같은 앱을 열어 활성화한 뒤 정상 화면을 확인했다. 실행기·게임 코드 수정은 필요하지 않았다. 이후 15.017초 동안 화면 갱신 847개를 측정했다. 평균 17.71ms·95백분위 18ms·최대 75ms이며, 전투 실패에서 메뉴로 돌아오는 구간의 기록이다. 지속 전투 성능 기준으로 사용하지 않는다.

일반 앱은 치트 기능을 켜지 않은 빌드다. Apple·Android는 기존 개발 서명 설치 절차를 사용했고, Tauri·웹은 Release 산출물을 사용했다. 앱 내부 버전 표기는 이번 배치 패치에서 바꾸지 않았다. [버전 표기 후속 과제](../usability-todo.md#hm-release-version--다음-릴리스-버전-표기-정리--2026-11-02).

검사한 작업 브랜치에서 develop, main 순서로 병합하고 공개 웹과 다운로드를 갱신한다. 이 문서 작성 시점에는 원격 병합·공개 배포 전이다. 완료된 원격 커밋과 배포 주소는 후속 실행 기록에 남긴다.
